# רתם שפירא — פילאטיס

אתר תדמית סטטי בעברית, מותאם לנייד ולמחשב. לפתיחה מקומית יש לפתוח את `index.html` בדפדפן. אין צורך בהתקנה או בבנייה.

## קבצים
- `index.html` — תוכן העמוד ואיורי SVG מקומיים.
- `styles.css` — עיצוב רספונסיבי, תמיכה ב־RTL ומצבי מיקוד.
- `script.js` — תפריט נגיש למובייל. ללא JavaScript, קישורי הניווט נשארים גלויים.

## היקף
העמוד כולל פתיח, אודות, פילאטיס מזרן ורפורמר, מאגר תרגילים לבניית שיעור של 50 דקות ופרטי קשר. המאגר מציג שמות תרגילים מהרפרטואר הקלאסי המיוחס לג׳וזף פילאטיס; משכי התרגילים הם הצעות לתכנון, וניתן לערוך אותם. המספר 054-802-4606 מופיע כטקסט בלבד, ללא קישור חיוג. אין טפסים, שליחת הודעות, הזמנות, מעקב או שירותים חיצוניים. הגופנים מבוססים על הגופנים המותקנים במכשיר.

התוכן המקצועי הבסיסי: רתם שפירא, מדריכת פילאטיס מזרן ורפורמר, בוגרת מרתה פילאטיס. נוסחי האודות והאווירה הם טיוטה לעריכה ולאישור רתם לפני פרסום.

תמונות אישיות, לוגו, אזור פעילות, מחירים ושעות לא סופקו ולכן אינם מוצגים. האיורים דקורטיביים ואינם הוראות לביצוע תרגילים. פרסום ברשת וחיבור דומיין אינם חלק מהגרסה המקומית.
